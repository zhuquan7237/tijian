题笺 8.16.0：拍完就能看懂，明天再复习，攒多了再打印

每天的用法收成一条线：拍照收录 → 读解析 → 就这道题追问 → 明天复习 → 错题多了再打印总复习。

- 首页底部常驻「拍照收录」。工作台是空的时候会直接打开相机，不必先看一张空桌子。
- 确认入库后打开这道题，解析默认展开。一批题可以上一题、下一题。解析下面就能追问，快捷句会带上这道题的题干和解析。
- 新收录的题第一次复习排到明天，不再刚拍完就堆进「今天到期」。已经在复习的题，间隔不变。
- 首页列出今天要复习的题，标星的排在前面。每天默认最多 8 道，多出来的留到后面。可以一键标成掌握或不重要，让出名额，也能撤销。
- 每天 20:00 本地提醒今天要看的题，时间可改。Android 13 及以上会先请求通知权限。开机后提醒仍在。
- 复习用上次记住的题量，点一下就开始。没做完的一轮会记住，进程被杀掉也能接着做。评分连点不会把同一题记两次。揭晓答案前不再放追问球。
- 按主题勾选再打印。几个小题类可以合成一份，大题类可以只挑标星或逐题选，也可以一次全选。默认只印题目和作答线，答案需要单独打开。一题一页，原图留在本页。
- 界面改成暖纸 / 暖石墨配靛蓝。中文标题不再加字距。

数据库从 7 升到 8：只给从来没安排过复习时间的旧题补上「创建后一天」。其他数据不动。
