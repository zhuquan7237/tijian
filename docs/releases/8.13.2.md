题笺 8.13.2：新手上手更快，进度再也不会丢

新用户三岔口

- 首次打开提供「体验示例题 / 直接收录错题 / 配置 AI」三条路：示例题内置三道典型题，不配置 AI 就能完整体验复习闭环。
- AI 接入页只保留服务商、密钥、模型三项必填；协议与思考强度收进「高级设置」。
- 「验证能否识别图片」改为发送真实测试图，报错直接给出下一步：密钥无效改密钥、模型不支持图片换模型、404 提示补 /v1。
- 从导入任务跳去配置 AI，保存后自动回到刚才的导入。
- 「手动录入」名副其实：直接输入文字即可建题，图片选填、随时补图。

进度不丢

- 待确认题目自动落盘：进程被杀后打开应用照常继续校对，首页显示「继续校对 N 道题」。
- 停止识别保留已识别完成的部分；识别失败只重试失败的图片。
- 题目编辑、草稿编辑自动暂存，误触返回不丢。

复习更灵活、可纠错

- 开始前可选 5 题 / 10 题 / 全部，记住上次选择；到期复习 / 专项练习 / 自由练习三种模式标明。
- 自评按钮改为「不会 / 不熟 / 掌握」，并显示预计下次复习时间。
- 支持撤销上一题评分；完成页列出本轮不会的题，可一键再练。
- 揭晓答案前原图默认隐藏，防止原图里的手写答案或批注提前剧透。

找题与浏览

- 首页搜索框常驻，直接搜题干、题号、知识点；「＋添加错题」固定带文字按钮。
- 分类页新增学习列表视图（默认）：两行题干 + 缩略图 + 知识点 + 掌握状态；整理表格保留，筛选新增「待复习」。

详情页

- 阅读之外新增练习模式；题干与原图快捷切换，不再重复占屏。
- 「答案与解析」「笔记」可折叠并记住选择；新增错因四选项：概念不清、方法没想到、计算失误、审题遗漏。
- 长文编辑改为完整页面：自动暂存 + 排版预览。

后悔药

- 删除后短暂可「撤销」；新增回收站，可恢复或彻底删除。
- 恢复备份前自动保存当前快照；显示上次备份时间与包含的题数。

阅读舒适度

- 应用内阅读字号三档（标准 / 大 / 特大），题干、解析、复习页、知识文档即时生效。
- 修正复习自评区被追问悬浮球遮挡的问题。
