题笺 8.15.0：渲染、排序与编辑器专项修复

- 题目列表/首页最近导入的公式真渲染：换用 JLatexMath Android 分支直接光栅化（此前 Markwon 管线在部分题干上静默回退成源码）；支持 $...$、$$...$$、\(...\)，识别漏写定界符的裸 LaTeX 段也能渲染；单条公式失败只回退原文。
- 长按拖动排序修复：拖动中不再「往下拖往上跳」（去掉错误的位移补偿，交换后按新槽位重新对齐手指）；长按后不再误触进入题目。
- 分类页「表格」换成「网格视图」：缩略图为主、题型徽标与题号一目了然，一屏看更多题。
- 笔记常驻：详情页笔记栏始终显示，文字就地输入自动保存，拍照/相册随时可加；缩略图不再显示叉号，预览页内提供「删除」与「编辑」。
- 图片编辑器新增：小角度微调（±15°）与 90° 整数旋转（画布外扩不裁内容）、透视四角校正（拖四个角点拉正拍歪的纸面，投影数学有单元测试）；工具栏重排为「裁剪 / 旋转 / 校正 / 画笔」。
- 追问悬浮窗重做：消息区与操作区底色分层，附件入口改为「+」菜单（发送图片 / 发送文本文件）；选中文字出现左右拖动手柄可精确扩选，「复制」条会在点空白后收起（修复常驻不消失的 bug）。
- 一键大整理升级：新增本地查重（内容相同的重复题保留最早一道，其余进回收站）；AI 复核升级为逐题检查答案与解析——算错、缺漏、或「先给答案再补过程」的都会重写，提示词明令先推理后结论、不得照抄题面已有答案。
- 新增「联网搜索」开关（AI 接入 → 高级设置）：按服务商注入参数（阿里百炼 enable_search、OpenRouter :online、智谱 web_search），是否搜索由模型按需判断。
- 识别与解析补全提示词同样加入「先推理后答案」铁律；SVG 等非位图文件在编辑器中给出明确错误提示。
