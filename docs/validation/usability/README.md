# 三批易用性改进

本次保持版本号，不发布 Release。新增功能默认兼容现有数据库版本，通过 setting 表保存草稿、阅读偏好和复习会话。

## 功能验收

- 第一次使用：示例题、直接收录、AI 配置；文字录入无需图片。AI 高级参数折叠，图片能力测试使用本地随机数字图片并校验返回值（会产生 API 请求）。
- 导入：每张完成即保存，校对修改自动保存，重启恢复；单张失败可重试；稍后继续与确认丢弃分离；入库以草稿 ID 保证重试幂等。
- 查找：常驻搜索支持题干、题号、知识点；默认学习列表，可切换整理表格，增加到期筛选；最近阅读入口。
- 阅读：阅读/练习切换、原图按需展开、解析隐藏、知识点和笔记折叠、错因快捷标记；全屏编辑与预览，编辑草稿恢复。
- 复习：5/10/全部，可选到期/专项/自由；会话持久化、撤销最近一次评分（同时恢复计划和日志）、完成统计和重练不会题。原图默认隐藏，用户主动查看时提示可能含答案。
- 数据：删除撤销和回收站；彻底删除需确认；恢复前自动快照可从设置导出；备份移除当前和常用服务商 Key，验证数据库完整性与图片、重定位图片路径。
- 舒适度：阅读字号 15/17/19/22，正文与公式跟随系统缩放；辅助文字提升至 13sp；编辑器避让系统栏和键盘，表格可横向滚动。

## 自动化覆盖

- SessionCodecTest：公式、分类、题号、全部草稿字段序列化；无图草稿；复习间隔边界。
- UsabilityDataTest：无图入库/幂等重试、题号字面量搜索、回收站恢复/彻底删除、评分撤销与日志。
- UsabilityUiTest：1.5 倍系统字体下全屏编辑保存入口可见，输出截图。
- 保留现有图片、富文本、公式、导入事务和布局回归测试。

## 发布前人工检查

真实设备检查软键盘、系统返回、进程回收、长公式横滑和连续切页；真实 API 验证需使用自己的服务商密钥。自动化不代替真实设备手感与服务商兼容性验证。
