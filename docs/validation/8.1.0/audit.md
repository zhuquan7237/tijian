# 题笺 8.1.0 UI 与交互检查

基线：c80a2ad（GitHub v0.8.1），版本号按本次要求设为 8.1.0 / 8010000。

## 全局规范

- 页面边距 20dp；布局采用 4/8/12/16/24/32dp 间距。
- 中性白与石墨色为主体，靛蓝用于状态和知识点强调。
- 主操作深色胶囊、次操作浅灰胶囊；最小高度 48dp，文本变大时可增长。并列操作等宽等高。
- 输入框 16dp、主要卡片 24dp、内部容器 12dp；搜索、编辑及设置表单复用 TjTextField。
- 图标操作统一 48dp；拍照缩略图删除操作不再挤在 26dp 内。
- 新图标覆盖 5 档传统图标、圆形图标、自适应前景及 README 图标；自适应前景增加安全留白。

## 检查与修改

| 页面/功能 | 找到的问题 | 修改 |
| --- | --- | --- |
| 错题本 | 搜索关闭后 query/results 残留；底部有大量无用途空白 | 关闭搜索同步清空；收敛底部间距；无到期题时提供自由复习，无错题时直接导入 |
| 分类 | 表格最大 520dp 与固定统计/操作区争夺高度；筛选后选择集与导出集不一致 | 列表使用剩余空间；筛选时清空选择、数据变化后取有效交集 |
| 导出 | 分享和保存按钮高度 50/44dp、圆角与字号不一致；失败后 busy 不清理 | 共享 TjButton；withBusy 在 finally 恢复状态并展示错误 |
| 拍照 | 重复 URI 作为 LazyGrid key；无批次上限；相机不可用时异常；删除按钮 26dp | 去重并限制 9 张；捕获相机启动失败；删除触控 48dp；临时 URI 支持状态恢复 |
| 识别校对 | 表单与底部操作样式各异；移除题目只有 18dp | 统一输入和主要操作；独立移除图标按钮 |
| 知识库 | 文档导出异常后 busy 可能滞留；生成过程没有一致反馈 | 导出使用 withBusy；库页与文档页明确加载状态 |
| 知识文档编辑 | 猜测导航栏高度导致不同机型留白不一致；空标题仍可点击保存 | safeDrawingPadding + imePadding；空标题禁用保存 |
| AI 接入 | 切换服务商还复用旧模型列表；拉取可重复触发；按钮与输入框风格不同 | 更换地址后清理模型缓存与错误；加载保护；共享控件 |
| 备份恢复 | 选择 zip 后直接覆盖数据 | 在选择文件后明确确认覆盖 |
| 聊天 | 至少 320dp 的面板在键盘弹出后可能超过可用高度；返回会退到上一页 | 面板跟随实际可用高度；小屏收起快捷区和缩短引用；返回先关闭面板 |
| 聊天 | 第一次发送失败不展示错误；大原图直接解码做缩略图；WebView 初载可能拿旧消息 | 错误展示移出消息分支；Coil 按需加载缩略图；初载读取最新状态并释放 WebView |
| 导航 | 平级页面为 65dp 底栏预留 86dp；隐藏页面仍暴露无障碍节点 | 统一底栏预留；只向无障碍服务暴露当前页面 |
| 原图编辑 | 工具按钮偏小；窄屏颜色与笔宽控件横向挤压 | 工具栏可横向滚动，操作目标至少 48dp |
| 更新 | 无 update.json 时的版本码公式与构建脚本相差 100 倍 | 统一为 major×1000000 + minor×10000 + patch×100 |

## 发布与边界

仓库未包含旧版签名私钥。本轮可以构建预览包，但新生成的调试密钥与旧版不同，不能作为覆盖升级包发布。

已提供原签名环境变量、签名证书校验、跨平台发布脚本，以及 GitHub Actions 构建/回归/发布流程。正式发布需要原签名密钥，不能从公开 APK 中恢复私钥。

旧版证书 SHA-256：`b304c3bf17ed5acb3c622c460de2db919d81d38f1763a6a104bcf079cb0fcf46`。

未覆盖真实手机、线上自定义模型接口、所有 Android 相册供应商、长时间性能及所有大字体/横屏组合；本轮不能声称修复全部潜在问题或保证稳定 60fps。
