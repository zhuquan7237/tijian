# 0.4.3 子分类卡片、原图编辑、材料专业课与 PDF 排版验证记录

环境：2026-10-19，Windows 本地构建；AtlasRefactorQA / emulator-5554，Android 17 API 37，1080×2400。Kotlin + Jetpack Compose、自建 Route/AppVm、本地 WebView/KaTeX；未新增依赖。

本版针对用户截图里的四类问题做代码修改：子分类卡片只有文字可点、原图编辑器布局和画笔、专业课材料类分类、PDF 大量空白。物理手机尚未验证；性能验收边界见文末。

## 根因与修复

| 问题 | 根因 | 本版修改 |
| --- | --- | --- |
| 子分类卡片空白处点不开 | `TextButton` 只有文字区域消费点击，外层 `CardBox` 没有点击修饰符 | 整卡 `clickableNoRipple` 进入分类，删除按钮单独保留点击区；增加进入箭头和题数/掌握度信息 |
| 原图查看布局不合理、底部按钮显示不全 | 图片和控件同处一个自适应 Column，长图把工具行挤出可视区；舞台深色底与纸张反差割裂 | 图片区固定权重、工具栏和主按钮使用独立紧凑行；舞台底色改为纸白；左右收窄到 22dp，四角操作避开系统返回边缘 |
| 原图不能做小记号 | 只有缩放/裁剪，没有标注能力 | 新增画笔：4 种颜色、细/中/粗、撤销、清空；笔迹坐标相对图片存储，缩放/裁剪后仍贴合；保存时叠加到无损 PNG 副本，未裁剪源图继续保留 |
| 边界裁剪缺少验证 | 原测试只测拖框和缩放 | 新增画笔落图与纵向原图几何测试；模拟器实际拖动裁剪框并保存 |
| 专业课分类空泛 | 只有“专业课”大类，未限定材料类小类 | 明确专业课为材料类，参考《材料科学基础》（上海交通大学出版社第三版）；数据库 v3 一次性写入晶体结构、晶体缺陷、固体扩散、相图与相变、金属材料、高分子材料、陶瓷材料等小类，可增删 |
| 材料题 AI 误归其他 | 分类提示词没有材料学科约束 | 识别与归档提示词补充材料类范围和小类示例；旧数据按既有学科规则兼容 |
| 导出 PDF 第一页几乎空白 | 先创建封面页，再无条件 `newPage()`；导出默认一题一页 | 删除空白封面页，标题缩到页面顶部；一题一页从第二题严格分页，题块内按实际可用高度缩放 |
| PDF 长图产生“图条页” | 原逻辑只在当前页放不下时整页翻页，图片、答案和解析各自占一整页 | 题块统一计算高度，图片按剩余空间二次缩放；答案/解析与题干同页排布；剩余内容超出才续页 |
| 输入框边界与文字对比不足 | 默认 Material 轮廓在浅底上过淡 | 统一 `tjFieldColors()`：深色正文、灰蓝描边、强调色焦点；题干/答案/解析/笔记/题型全局应用 |

## 文件与关键实现

- `ui/SubjectScreen.kt`：整卡点击、删除独立点击区、材料类副标题。
- `ui/ImageEditor.kt`：纸白舞台、画笔与撤销清空、颜色/笔宽、`exportWithStrokes` 无损叠加、图片区固定权重和左右 22dp 安全边距。
- `data/Db.kt`、`data/Models.kt`：schema v3 材料小类初始化；迁移只在 `category` 表存在时写入；材料关键字归专业课。
- `ai/AiClient.kt`：识别/归档提示词增加材料类参考书和子类。
- `export/PdfExporter.kt`：无封面、题块高度统一预判、图片按可用高度缩放、答案/解析续排。
- `ui/Theme.kt`、`ui/HomeScreens.kt`、`ui/ImportReview.kt`：字段颜色、正文可读性、卡片阴影。
- `app/src/androidTest/java/com/zhuquan/tijian/ImageEditorLayoutTest.kt`：画笔落图、纵向原图几何、PDF 单页题块。

关键实现：画笔存的是 `Offset(x/width, y/height)`；导出用原图方向矩阵叠加笔迹；PDF 的 `image(..., maxHeight)` 同时限制宽高比，避免裁掉图片。

## 实际测试

- `assembleDebug`、`assembleRelease`、`assembleDebugAndroidTest`、`lintDebug` 成功；lint 0 errors、17 warnings（弃用 API、ExifInterface、自定义 View 构造器等既有项）。
- Android 仪器测试 13 项全部通过（29.342s，`docs/validation/0.4.3/instrument-043.xml`）：原有 10 项加画笔像素叠加、纵向原图全貌、PDF 题块排版。
- PDF 自动化导出使用 1000×3000 长图，生成 1 页；逐页渲染检查图片、答案、解析均在同一页，无“只有答案的第二页”。
- 模拟器交互：子分类卡片中部点击可进入；原图编辑器实际截图检查裁剪、画笔、撤销、颜色/笔宽和保存；保存后详情图片更新，源图仍可查看；空内容与有内容详情均可滚动。
- 数据库迁移测试覆盖 v1→v2→v3：缺少 `category` 表的旧库不会崩溃，材料小类不会因读取操作反复复活。

## 性能与边界

模拟器上一版 0.4.2 的 release 采样仍为 71/209 超时帧（33.97%），P95 44ms；本版未重新做长时性能基准，不能据此宣称转场已经达到稳定 60fps。物理手机、线上 AI 服务、全部相册供应商/图片格式未验证；旧版已经压缩或裁剪的图片无法恢复丢失像素，需要重新导入。

截图和仪器 XML 位于 `docs/validation/0.4.3/`。`subject-cards-043.png` 为整卡点击后的子分类页；`editor-layout-043.png` 展示工具行完整可见；`editor-brush-043.png` 为真实画笔笔迹；`editor-crop-043.png` 为自由裁剪框；`pdf-single-page-043.png` 与 PDF 文件是实际长图导出的逐页渲染。

材料小类在已有数据库上通过升级写入一次；用户删除后不会在重启时重新创建。若旧库的分类表缺失，则跳过种子写入，避免首启崩溃。
