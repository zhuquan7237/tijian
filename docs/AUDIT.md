# 题笺 8.16.0 审计

对照的是每天真实的用法，而不是功能清单：

1. 拍下一道错题
2. 读 AI 的解析
3. 就这道题追问
4. 以后再复习
5. 错题攒多了，打印出来做一次总复习

8.15.1 把这五步拆成了仪表盘、工作台、校对页、悬浮球、复习设置和分类里的多选导出。每一步都要先找入口，所以用起来像负担。

本版没有删功能。知识库、备份、回收站、整理、多服务商都还在。改的是主路径怎么接上，以及几处会记错数据或把进度弄丢的逻辑。

数据库从 7 升到 8，只给「从未安排复习时间」的旧题补上 `created_at + 1 天`。已有掌握度和复习计划不动。备份包结构不变。

## 这条路径现在怎么走

| 步骤 | 8.15.1 | 8.16.0 |
|---|---|---|
| 拍照 | 首页要滚到「添加错题」，再进空工作台，再点拍照 | 首页底部常驻「拍照收录」，空工作台会直接打开相机 |
| 读解析 | 确认入库后回到首页，要自己再找这道题 | 入库后打开这道题，解析默认展开；一批题可以上一题 / 下一题 |
| 追问 | 靠右下角悬浮球，复习时还会挡住自评 | 解析下面就是「还没看懂？」和两条直接发出去的追问；复习揭晓前不放追问球 |
| 以后复习 | 新题 `next_review_at = 现在`，刚拍完就堆进「今天到期」；每次还要再选一次题量 | 新题第一次复习排到明天；首页用上次记住的题量一键开始 |
| 打印 | 要进某个分类，打开多选，再导出；答案跟在每题后面，打印出来没法先做 | 首页「按主题打印」：按主题勾选，几个小题类可以合成一份；大题类可以逐题选，或只选标星。默认只印题目和作答线，答案要单独打开 |

## 缺陷

严重程度：高 = 会丢数据、记错复习，或让主路径走不下去；中 = 每天都会多几步或看错信息；低 = 别扭，但不挡事。

### 缺陷（bug）

| 问题 | 严重程度 | 处理 |
|---|---|---|
| 复习评分的队列下标写在数据库读取之后。注释写「先推进再落库」，实际连点会给同一题记两次 | 高 | 主线程先把下标加一，再异步落库 |
| 首页「开始复习」会覆盖还没做完的一轮 | 高 | 有未完成的一轮时，主按钮是「继续复习」；设置里才有「放弃本轮，重开」 |
| 复习进度只在内存里，进程被系统杀掉就没了 | 高 | 写入已有的 `setting` 表（`review.session`），不改题目表。做完或主动结束才清掉 |
| 分类页右上角「+」进入空的「识别校对」，而不是收录 | 中 | 与首页同一套 `openAdd()`：有待确认就去校对，有待导入图片就回工作台，否则打开收录面板 |
| `next_review_at` 为空或 0 的旧题永远不进到期队列 | 中 | 数据库 v8：这些题补成「创建时间 + 1 天」。已有计划的题不改 |

### 逻辑

| 问题 | 严重程度 | 处理 |
|---|---|---|
| 新收录的题立刻到期。拍完、读解析、追问和「今天要复习」叠在一起，首页数字变成欠债 | 高 | `firstReviewAt` = 收录时间 + 1 天。间隔算法（0/1/3/7/16/35）不变，避免打乱已经在复习的题 |
| 新题上「不会 / 不熟 / 掌握」的下次出现时间经常都是「明天」，看不出掌握度变了没有 | 中 | 间隔算法不动；按钮副文案改成「明天 · 降 / 保持 / +1」 |
| 揭晓答案前追问悬浮球盖住作答，也让人提前问 AI | 中 | 复习页在揭晓前隐藏悬浮球。追问留在题目详情，也就是刚看完解析的那一步 |
| 未配置 AI 时点识别会被突然带去设置页 | 低 | 保留这个保护（否则会得到一堆空草稿）。首页空状态写明：可以先拍照或手动录入，识别时再配置 |

### 设计 / 产品

| 问题 | 严重程度 | 处理 |
|---|---|---|
| 首页是仪表盘：64sp 的到期数字、五个经常是空的学科卡、搜索框常驻。每天要做的两件事（收录、复习）不是第一眼能点到的 | 高 | 主卡改成一句人话和一颗按钮（继续 / 复习 N 题 / 拍下第一道）。空学科收成一行。搜索收进顶栏 |
| 每次复习都要再选范围和题量，尽管选择已经记住了 | 高 | 主按钮直接用上次的题量。需要改时点「调整题量或范围」 |
| 最近导入是横滑图片卡，题干被裁掉，认不出是哪道题 | 中 | 改成竖排题干，并标上「明天复习 / 今天到期」 |
| 知识库和错题本是同等的底部 Tab | 低 | 保留。它不是这条主路径的阻塞点，删掉会丢掉已有文档 |
| 学科页副标题每次都在教「长按拖动排序」 | 低 | 改成「N 个分类 · N 道」 |

### 交互

| 问题 | 严重程度 | 处理 |
|---|---|---|
| 拍照要经过空工作台 | 高 | 「拍照收录」和收录面板里的「拍照」都会在工作台为空时打开相机。相册多选仍先回到工作台，方便裁剪 |
| 收录面板把相册放在拍照前面 | 中 | 拍照放第一项 |
| 确认入库后回到首页，解析和追问要重新找 | 高 | 入库后进入刚保存的题目。一批题用「上一题 / 下一题」串起来，解析默认展开 |
| 追问入口只有悬浮球 | 高 | 解析下方增加「还没看懂？」，两条快捷句直接发出，并带上当前题的上下文 |
| 撤销评分在顶栏，评分钮在底部 | 中 | 评分钮下面增加「撤销上一题」（顶栏入口仍保留） |
| 打印要先多选，答案印在题目旁边，不适合考前自己做 | 高 | 独立的打印页按主题浏览。主题可以全选，题可以逐题勾、标星、只选标星，也可以一次全选所有主题。PDF 默认不含答案和解析；一题一页，换主题有标题，原图按比例留在本页，页下留作答线 |

| 问题 | 严重程度 | 处理 |
|---|---|---|
| 中文标题用了负字距，小节用了 1.6sp 正字距，「今日复习」「思路」这类汉字被挤开或拉开 | 中 | 界面标题字距改为 0。富文本里的卡片标题、解析标签（`.an-tag`、`h4`）同样取消字距 |
| 高饱和蓝 + 大渐变数字卡像数据看板，不像练习本 | 中 | 日间改为暖纸 `#F6F3EC` + 靛蓝 `#3E4C7E`，夜间改为暖石墨 + 淡墨靛蓝 `#B7C0F0`。Compose 与 WebView CSS 一起改。PDF 打印仍用原来的浅色 `rt-print`，避免打印发灰 |

### 技术债

| 问题 | 严重程度 | 处理 |
|---|---|---|
| 复习进度没有落盘位置，再加表会动到备份和迁移 | 中 | 复用 `setting` 表。备份本来就会带走 setting，并单独清掉 API Key，复习进度会跟着备份走 |
| 入库只返回「保存了几道 / 跳过了几道」，界面无法跳到新题 | 中 | `saveDrafts` 改为 `SaveResult(saved, skipped, ids)`。仪器测试已改成读这三个字段 |
| 打印范围要在界面里临时拼查询 | 低 | `questions()` 增加可选的学科条件，走现有的分类连接，不新开表 |

## 复习提醒（主人会忘掉要看哪几道）

每天的复习如果只靠自己想起来，重要的题会被淹没。8.16.0 用间隔重复排出一份短名单，并在设定时间本地通知。

- 进入名单的条件：已经到期、掌握度不到 4、没有标成「不重要」。标星的排在前面。
- 每天默认最多 8 道（可改成 5 或 10）。多出来的留在库里，这批做完或到了下一天再轮到，不会一次堆满。
- 首页「今天的题」列出这几道。每道可以一键「掌握」或「不重要」，立刻让出名额；底部撤销条可以改回来。题目详情里也能「重新加入」。
- 提醒默认每天 20:00，在「我的 → 复习提醒」里改时间或关掉。Android 13 及以上先说明再请求通知权限；拒绝之后清单仍在首页，不会反复弹窗。
- 用 AlarmManager 定到下一次时刻。能精确闹钟就精确，系统不允许就退回允许休眠唤醒的闹钟。开机、改时间、改时区都会重新登记。没有到期的题那天不发通知。

## 没有改的东西

- 掌握度升降和间隔天数。只改了「新题第一次什么时候出现」和按钮上的说明。
- 识别、分类、去重、草稿落盘、回收站、备份、应用内更新、知识库生成。
- 原图在揭晓答案前默认隐藏（原图里可能有手写答案）。
- API Key 仍只在本机数据库，备份包里会去掉。

## 验证

- 单元测试 `JourneyRulesTest`：新题的第一次复习是收录后一天；复习进度 JSON 能来回读写。
- `./gradlew test assembleRelease` 需要本机 Android SDK。发布签名仍走 `scripts/release.sh` 里的原证书校验，本仓库的 debug 签名不能当正式升级包。
