# 题笺 8.3.1 验收记录

## 返回时闪屏 / 过渡不统一

8.3.0 只修了进入方向，返回仍旧闪。根因有三个，全部修掉：

1. **旧页被提前回收**：`route` 刚变、过渡还没启动的那一帧，清理逻辑会命中并删掉即将参与退场动画的页面，返回时旧页瞬间消失。
   → 动画结束后再延迟清理。
2. **不透明背景盖住了旧页**：页面背景画在 alpha 层外面，新页一上来就用底色盖住整屏，所以只剩“白闪”。
   → 背景和内容一起淡入。
3. **每页 `animateFloat` 在部分页面直接拿到终值**（alpha 恒为 1），看起来像硬切。
   → 改成一条显式的 `Animatable` 进度：`remember(route)` 在 route 变化的那次 composition 里同步从 0 开始，旧页保持不透明，新页 0→1 淡入并位移 4%；旧页反向 2%。

现在进入、返回、同级 tab 共用同一套逻辑：任何一帧至少有一页不透明，不再有空白帧。

## 详情页闪“正在读取题目…”

页面被重建时 `q` 从 null 开始，会闪一下加载态。现在题目详情在 ViewModel 里做了内存缓存，重进/返回同一题直接出内容；掌握度修改、编辑保存都会同步更新缓存。
