# 题笺设计系统（software-design workflow）

> 方向：**书桌**（8.16.0 起）。日间暖纸 + 靛蓝 `#3E4C7E`，夜间暖石墨 + 淡墨靛蓝 `#B7C0F0`。
> 层级靠明度（Bg < CardBg < SurfaceAlt < Fill）。中文标题字距为 0。
> 8.9.0–8.15.1 为「夜读台」（深石墨 + 品牌蓝 + 大数字主卡）。更早的浅色方案见 `docs/ui/v050`–`v082`。

## 字体

系统无衬线（设备默认），靠字重与字号建立层级：

| 角色 | 字号 / 行高 | 字重 |
|---|---|---|
| 页面大标题 | 32 / 40 | Bold |
| 卡片标题 | 15 / 22 | SemiBold |
| 正文 | 15 / 25 | Normal |
| 列表主文 | 13 / 19 | Normal |
| 说明 / 标签 | 11–12 / 18 | Normal / Medium |
| 数字主视觉 | 40–52 / 1.0 | Bold |

规则：正文行宽 < 80 字符；中文正文行高 ≥ 1.6；不用全大写标签、不给标题里的单个词换色。

## 布局

- 页边距 20dp；卡片圆角 18dp；内边距 16dp；卡片间距 16dp。
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32。
- 一级页面统一 `top bar + 内容 + 底部 tab`；二级页面 `top bar + 滚动内容`。
- 列表用 1dp 分隔线，不用每行一张卡。

## 动效（`ui/Motion.kt`）

| Token | 值 | 用途 |
|---|---|---|
| `Fast` | 120ms | 按压、颜色/图标状态 |
| `Base` | 180ms | 面板、提示、掌握度选中 |
| `Page` | 260ms | 页面 push/pop |
| `Enter` | `cubic-bezier(.23,1,.32,1)` | 进入：起步快、立刻有反馈 |
| `Move` | `cubic-bezier(.77,0,.175,1)` | 屏幕内位移 |
| `Exit` | `cubic-bezier(.4,0,1,1)` | 退出，比进入更快 |

规则：
- UI 动效 ≤ 300ms；按压 100–160ms；退出快于进入。
- 只动 `transform` / `opacity`，不动宽高与边距。
- 不从 `scale(0)` 进入；最小 `scale(0.95) + opacity 0`。
- 页面切换：push 新页整屏推入、旧页 `-W/2 + scale .7 + fadeOut`；pop 反向；一级 tab 用 fade-through（旧页先出、新页再入）。
- 系统“减少动画”开启时，Compose 的 `tween` 会随 `animator_duration_scale` 归零，自动退化为硬切。

## 组件规则

- **按钮**：高 ≥ 48dp；主按钮深墨底白字；按压 `scale(0.97)` + 触感；同一流程里动词保持一致。
- **卡片**：白底 + 1dp `Line`，阴影只用于浮层；同屏不要超过两级圆角。
- **Chip**：选中深墨底白字，未选中白底 + 1dp 边；触控 ≥ 48dp。
- **输入框**：1dp `FieldBorder`，聚焦时 `Accent`；错误文案说明“怎么修”，不道歉。
- **空状态**：一句说明 + 一个明确动作，不用插图占位。
