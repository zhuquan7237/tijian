# 题笺 8.2.0 验收记录

## 本轮修复

### 1. 长按选择（详情 / 解析 / 选项）
- 8.1.0 的问题：为了去掉系统菜单，页面设置了 `user-select:none`，并用 JS 自己算“词”，用户看不到选区、也没有手柄，实际不可控。
- 8.2.0：恢复 WebView 原生选区（蓝色高亮 + 左右手柄，可拖动扩选），在 `TjWebView.startActionMode()` 拦截系统菜单，只保留「复制」「追问」两项。
- 验证：长按题干中的公式，出现原生高亮 + 两个手柄 + 浮动菜单；点「追问」打开悬浮窗并带上选中文字。

### 2. 切换界面重影
- 根因：页面切换使用位移动画 + 0.96 alpha 交叉淡入，WebView 在动画期间会残留上一帧。
- 修复：路由切换改为硬切（`tween(0)`），旧页在下一帧 alpha=0，不做位移。
- 验证：首页 / 知识库 / 我的 三个 tab 连续切换无残影。

### 3. 题目缩略图
- 分类题目列表：缩略图 48×60 → 56×70，行高 80 → 88dp，表头列宽同步。
- 追问面板：题目缩略图 56 → 64dp，加 1dp 边框；文件不存在时回退到题型首字，不再出现空白块。
- 验证：分类列表三行均显示题目原图缩略图；追问面板左上角显示当前题原图。
