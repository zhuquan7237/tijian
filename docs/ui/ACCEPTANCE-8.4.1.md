# 题笺 8.4.1 首页 Tab 切换

## 问题

底部「错题本 / 知识库 / 我的」切换仍然闪：两页同时半透明叠着，文字互相压在一起；底栏还会换实例跳动。

## 根因

1. **交叉淡化导致重影**：之前是“旧页保持不透明、新页淡入”，中途两页文字叠在一起，看起来就是闪。
2. **底栏在动画期间被替换**：页面内的 BottomBar 换成顶层 BottomBar + 65dp Spacer，高度/层级不完全一致，切换瞬间会跳。
3. **Tab 冷启动**：页面第一次被点到才组合，数据 `LaunchedEffect` 现加载，出现空白再填充。

## 修复

- 一级 Tab 改用 **Material fade-through**：旧页在动画前 30% 时长内淡到 0，新页从 30% 处再淡入。两页不同时可见，没有重影。
- 删掉顶层 BottomBar 和 Spacer，底栏始终留在各自一级页内部，动画期间不换实例。
- 启动时就把 `Home / Library / Settings` 放进 `pages` 常驻组合，切换不再触发布局/数据加载。

## 验证

- 10x 慢放截帧 `52-tab-mid.png`：旧页已完全淡出，只剩知识库页面，没有文字叠加；底栏位置稳定。
- 这套逻辑已沉淀为 skill `compose-page-transitions`（含 RikkaHub 的 NavDisplay 参数、移植配方与全部坑）。
