# 题笺 0.5.0 · 界面与交互重设计

> 本文记录 0.5.0 视觉改版的方案探索、评分依据、最终 token 与逐页改动。
> 所有对比度为 WCAG 2.1 公式实测（`docs/ui/contrast.py`），触控尺寸来自
> `uiautomator dump` 的真实 bounds（1080×2400 / 420dpi，1dp = 2.625px）。

## 1. 三套方向

同一信息架构（复习主卡 + 学科入口 + 最近导入 + 三 tab），三种视觉语言：

| | A · 墨白 Editorial | B · 暖纸 Scholar | C · 夜蓝 Focus |
|---|---|---|---|
| 底色 | 冷灰白 `#F5F6F8` | 象牙 `#FAF6EC` | 深墨 `#0E1218` |
| 主色 | 靛蓝 `#2F4BD8` | 赤陶 `#B4553A` | 青绿 `#35D0A5` |
| 字体 | 无衬线，字重分层 | 衬线标题 + 无衬线正文 | 无衬线 |
| 气质 | 克制、像印刷题集 | 温和、像装帧笔记本 | 夜间专注 |
| 风险 | 情绪偏冷 | 暖底长读易疲劳；强调色对比不足 | 白天户外反光下可读性差；需维护双色板 |

对比图：`docs/ui/proposals.png`（左 A / 中 B / 右 C，每列上首页下详情）。

## 2. 评分

权重：对比度可达性 25 / 层级清晰 20 / 长期可读 15 / 实现与一致性成本 15 /
品牌识别 15 / 差异化 10。对比度得分由实测通过项与余量换算。

| 维度 | A | B | C |
|---|---|---|---|
| 对比度可达性（25） | **25**（全部文字项 PASS，正文 16.8:1，次要 5.4:1） | 18（强调文字 4.02:1，未达 4.5） | 23（夜间强，白天反光扣分） |
| 层级清晰（20） | **18** | 16 | 15 |
| 长期可读/舒适（15） | **14** | 10 | 9 |
| 实现与一致性成本（15） | **14**（单一色板） | 12 | 9（需双主题） |
| 品牌识别（15） | 12 | **14** | 13 |
| 差异化（10） | 7 | 8 | **9** |
| **合计** | **90** | 78 | 78 |

**结论：采用 A 墨白 Editorial。** B 的强调色对比不达标（`#B4553A` on `#F2E8D8` = 4.02:1），
C 的白天可读性与双主题维护成本不适合作为唯一主线；A 在“错题长时阅读”这个核心场景
得分最高，且只需维护一套色板。

## 4. 逐页改动

### 首页
- 装饰性希腊字母占位卡 → **单列学科行**：语义图标（计算器/学士帽/翻译/法槌/分类）+ 题数 + 掌握进度 + chevron；0 题学科只显示一行“暂无错题”，不再出现 0/0。
- 深色复习卡：大数字 52sp、4dp 进度条（白 22% 轨道 + `#7C8FFF` 填充）、说明改为解释间隔机制；CTA 改为整宽 46dp。
- 顶栏新增实心强调色“导入”按钮，移除右下 FAB（原先会压住最后一张卡）。
- 副标题从重复的三段统计改为“N 道错题”；学科区不再重复计数。

### 学科 / 分类
- 学科页子分类卡：增加掌握进度条、危险色删除按钮、整卡 48dp+ 触控。
- 分类页表格：表头 11sp SemiBold + 浅灰底；行高 80dp；缩略图 48×60；无图时显示“无图”而不是空框。
- 筛选 chip 支持横向滚动，避免窄屏溢出；未选中描边提升到 4.0:1。
- 移除底部“导入错题”大按钮（与“复习这组”争主操作），导入移到顶栏“+”。

### 题目详情
- 掌握度改为独立卡片：0–5 六段，段高 44dp，选中态实心强调色白字，并给出“0 完全不会 · 5 能独立讲清”的语义说明。
- 移除右下 ExtendedFAB（遮挡内容），编辑/删除保留在顶栏；删除图标用危险色区分。
- 分区块色点语义固定：题目=墨、答案=绿、解析=强调、知识点=琥珀。

### 我的
- 增加“快捷操作 / 设置 / 关于”分组；统计卡数字可点（错题→首页，待复习→复习）。
- 行高提升到 64dp+，图标 36dp，标题 15sp，副标题 12sp；数字 0 降权为辅助色。
- 移除与“关于题笺”重复的顶栏 info 按钮；脚注升到 12sp/19sp。

### AI 接入
- “保存”改为实心强调按钮（40dp 高）。
- 字段标签统一中文；拉取按钮与输入框留 10dp；测试连接改为强调色描边按钮。
- 所有输入框使用可见边框（4.7:1）与近黑输入文字。

### 知识库 / 复习
- 生成卡图标语义化，按钮 36dp；“选择分类”整卡可点且有涟漪。
- 文档行图标、字号统一；PDF 按钮 44dp 触控。
- 复习页自评前增加“记得多牢”提示；自评按钮 50dp。

## 6. 验收标准

1. 正文/卡面对比 ≥ 7:1，次要文字 ≥ 4.5:1，功能边框 ≥ 3:1（实测见第 3 节）。
2. 所有可点目标 ≥ 48dp；列表行 ≥ 64dp。
3. 按压有涟漪或缩放反馈（`tjClickable` / `bounceClick` 统一入口）。
4. 无文本溢出/遮挡；关键页面截图 + `uiautomator dump` 双证。
5. `assembleRelease` + 单元/仪器测试通过；真机（模拟器）安装后按主流程走通。
